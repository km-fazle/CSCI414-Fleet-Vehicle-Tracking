# FleetTrace Lab

Simulated fleet tracking for CSCI 414/514 Option 10. Vehicles send synthetic positions to a FastAPI service, which stores them in MongoDB. The graded network is three Linux segments and a router, built with network namespaces inside one privileged Ubuntu container.

Docker Desktop supplies the Linux kernel. The container does not use three Docker bridge networks, because Docker would route those bridges itself and the project router would not see the traffic.

## Run the lab

From the repository root, with Docker Desktop running:

```bash
docker compose up -d --build
docker compose exec -T lab bash scripts/run-lab.sh
```

`make lab` does the same thing. The run writes logs, packet captures, and measurements under `evidence/`. It takes several minutes because the impairment trial sends 200 updates across a delayed link.

Remove the namespaces when you are finished:

```bash
docker compose exec -T lab bash scripts/teardown.sh
docker compose down
```

`docker compose down` keeps the MongoDB volume. `docker compose down -v` deletes it.

## Dispatch board

A browser view of the same lab, laid out as a fleet dispatch screen: live map, vehicle list, replay, the recorded baseline-versus-delay report, and service alerts.

```bash
make ui
```

Then open http://127.0.0.1:8787. The page reads the API from the client namespace, so the namespaces and services have to be up. `scripts/run-lab.sh` starts the board with the API. Publishing port 8787 recreates the lab container, which drops the namespaces; run `scripts/setup-network.sh` and `scripts/start-services.sh` inside the container after that.

The map shows synthetic tracks. It does not show GPS from a vehicle.

Unit tests alone:

```bash
docker compose exec -T lab pytest tests/unit -q
```

## What the lab checks

- Client `10.10.10.10`, router, API `10.20.20.10:8443`, MongoDB `10.30.30.10:27017`
- HTTPS with a lab CA. `curl` without that CA must fail
- Client connections to MongoDB time out; API connections succeed
- The same 200-update workload with and without `tc netem delay 150ms 20ms`
- An API outage of about 10 seconds, then a new write and read

Addresses live in `network/addresses.env`. The shared experiment size lives in `network/experiment.env`.

## Layout

`api/` is the FastAPI service. `simulator/` generates deterministic tracks and runs the timed workload. `scripts/` builds the network and the experiments. `network/firewall.nft` is the router policy. Private keys are generated by `scripts/generate-certs.sh` and are not committed.

Synthetic positions are not GPS tracks. See `data/README.md`.
